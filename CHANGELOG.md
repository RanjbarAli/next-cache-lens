## 0.1.0 - 2026-08-22

### Added

- Public Next.js 16 Cache Components handler integration with bounded in-memory caching
- Hashed identifiers, event aggregation, tag indexes, lifetimes, and deterministic diagnostics
- Development-only Route Handler with snapshots, reset, and safe tag revalidation
- Accessible React DevTools with overview, entry, tag, event, graph, and diagnostics sections
- Optional tracing wrappers for public `next/cache` APIs
- Real Next.js example, unit/integration/E2E suites, tarball consumer validation, and package documentation
